# HVAC Ops Pro

Tenant package for the HVAC contractor affiliate quiz funnel.

## Runtime Env

- `NEXT_PUBLIC_HVAC_OPS_PRO_META_PIXEL_ID`
- `HVAC_OPS_PRO_META_ACCESS_TOKEN`
- `HVAC_OPS_PRO_HOUSECALL_PRO_AFFILIATE_URL`
- `HVAC_OPS_PRO_JOBBER_AFFILIATE_URL`
- `HVAC_OPS_PRO_SERVICETITAN_AFFILIATE_URL`

The email templates link through the app click-through route so affiliate URLs can change through runtime env vars without code changes.
